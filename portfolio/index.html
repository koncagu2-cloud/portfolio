About this site

This portfolio uses Astro, TypeScript, semantic HTML, and CSS. Project records include evidence references; automated checks cover content provenance, keyboard navigation, responsive layouts, and accessibility.

One implementation decision. Navigation and project content are rendered as HTML, so they remain available without JavaScript. The theme toggle is an optional enhancement: it stays hidden without JavaScript, and still works for the current page if browser storage is blocked.
